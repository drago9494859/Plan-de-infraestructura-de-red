## 📌 Descripción del proyecto

Este proyecto presenta el diseño de una infraestructura de red orientada a garantizar la conectividad, la seguridad informática y la comunicación eficiente entre diferentes sedes.

## 🎯 Objetivo

Diseñar una infraestructura de red segura y organizada mediante dispositivos de red, conexiones WAN, firewalls y VPN IPsec.

## 🛡️ Tecnologías y componentes

- Routers y switches.
- Firewall y seguridad perimetral.
- Conexión WAN entre sedes.
- VPN IPsec para comunicación cifrada.
- Servidor Oracle.
- Cisco Packet Tracer.
