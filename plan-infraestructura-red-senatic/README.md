# Plan de Infraestructura de Red – SENATIC

Repositorio académico para organizar la documentación, diagramas, configuraciones y planes de operación de la infraestructura de red.

## Objetivo
Centralizar los archivos del proyecto de infraestructura de red de SENATIC para facilitar su consulta, actualización y trabajo en equipo.

## Estructura
- `documentacion/`: alcance, objetivos, requisitos e informes.
- `diagramas/`: topologías y diagramas físicos/lógicos.
- `configuraciones/`: ejemplos y archivos de configuración de dispositivos.
- `seguridad/`: políticas, controles y buenas prácticas.
- `inventario/`: inventario de activos tecnológicos y direccionamiento IP.
- `mantenimiento/`: mantenimiento preventivo y diagnóstico.
- `incidentes/`: reportes, procedimientos y recuperación ante fallos.
- `fuentes_originales/`: documentos de referencia proporcionados para el proyecto.

## Herramientas
- Cisco Packet Tracer: modelar y probar la topología.
- GitHub: guardar versiones y colaborar.
- Visual Studio Code: editar Markdown y archivos de configuración.

## Cómo usar el repositorio
1. Lee este archivo.
2. Revisa los documentos en cada carpeta.
3. Actualiza los datos pendientes solo cuando hayan sido verificados.
4. Registra cambios importantes mediante commits descriptivos.

## Importante
Los direccionamientos IP, contraseñas, nombres de equipos y datos de la institución deben verificarse antes de usarse. No publiques contraseñas, claves privadas ni información sensible.
