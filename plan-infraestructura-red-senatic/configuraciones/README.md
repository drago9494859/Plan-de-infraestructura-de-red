# Configuraciones de red

Guardar aquí archivos de configuración de ejemplo, comandos y notas para routers y switches.

Antes de usar una configuración:
1. Confirma el modelo del dispositivo y la versión de IOS.
2. Sustituye los valores de ejemplo por los autorizados.
3. Prueba los cambios en Cisco Packet Tracer o en un entorno de laboratorio.
4. No guardes contraseñas reales, claves privadas ni credenciales en el repositorio.
